# Mollie

Mollie is a statically typed scripting language for running code from strangers, like addons that players download, inside a game or an application. It looks a lot like Rust, has a garbage collector, and has a type made for describing user interfaces.

This book has two parts.

[The Language](language/index.md) teaches Mollie itself, from numbers and strings to traits, modules and views. It's written for people who are new to it, and to programming in general.

[Embedding and Internals](internals/index.md) is for people putting Mollie into their own Rust program, and for people working on Mollie. It covers the host API, how the compiler and runtime work, and the tools around them.
